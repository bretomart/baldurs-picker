# Baldur's Picker

Baldur's Picker is a fast, responsive party composition builder and companion planner for Baldur's Gate 3.

## Features

- **Party Composition:** Select and balance 4-character adventuring parties across all BG3 classes and subclasses.
- **Companion Synergy:** Track origin companion skill distributions, spell slots, camp roles, and dialogue proficiencies.
- **Role Balancing:** Live party analysis for frontline tanking, burst damage, crowd control, and healing output.
- **Zero-Latency Static Build:** Built with Vue and Tailwind CSS for instant client-side interaction.

## Development

```bash
npm install
npm run dev
npm run build
```

## Deployment

Continuous deployment is automated via GitHub Actions to GitHub Pages on pushes to `main`.
